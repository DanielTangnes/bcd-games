TimGM6mb.sf2: the General MIDI SoundFont BCD plays MIDI music with

What it is
  A 5.7 MB General MIDI bank (128 melodic instruments and the percussion kits).
  A game's MIDI music is played by Apple's synthesizer (AUMIDISynth) using this
  file, when a game opens a MIDI output device (env.MADEIRA_MIDI = 0 turns MIDI
  off; Documents/SoundFonts/ in Files can hold another bank to use instead).

  legal/LICENSES/GPL-2.0.txt).

How it is carried
  This file is not part of BCD's source repository and is not changed in any way:
  the build downloads it (tools/fetch-soundfont.sh), checks its SHA-256 and puts
  it next to this notice. It is a data file read by Apple's synthesizer, not a
  program linked with BCD, so it stays under its own licence beside BCD's (an
  aggregate, as GPL-2.0 and GPL-3.0 section 5 describe). A SoundFont is its own
  source: the file is the form in which it is edited (with Polyphone or Swami),
  and you may copy, change and share it under GPL-2.0.
